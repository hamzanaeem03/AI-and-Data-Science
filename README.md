## 👋 About This Repo

This repository is my learning log and portfolio for a structured **8-month AI & Data Science course** — covering Python, NumPy/Pandas, Data Visualization, Machine Learning, NLP, Deep Learning, Generative AI, Agentic AI, and deployment with Django & FastAPI.

Rather than one flat commit history, work is organized into branches by type. Browse them directly to see actual submitted work — this page is just the map.

---

## 🧭 Repository Guide

| Branch | What's in it |
|---|---|
| [`main`](../../tree/main) | 📍 You are here — overview & course map |
| [`Class-Tasks`](../../tree/Class-Tasks) | Exercises done at the end of each class |
| [`Weekly-Assignments`](../../tree/Weekly-Assignments) | Weekly assignments and mini-projects |
| [`Quizzes-&-Monthly-Exams`](../../tree/Quizzes-&-Monthly-Exams) | Quiz & monthly exam work |

```

Quizzes-&-Monthly-Exams/Monthly-Exam-2/
```

## 🗺️ Course Map

| Phase | Focus | Core Skills |
|---|---|---|
| 1. Python for Data Science | Foundations | Syntax, OOP, file/exception handling |
| 2. NumPy & Pandas | Data wrangling | Arrays, DataFrames, cleaning, grouping |
| 3. Data Visualization | Communicating data | Matplotlib, Seaborn, time series |
| 4. Machine Learning Essentials | Predictive modeling | Regression, Decision Trees, evaluation metrics |
| 5. NLP | Text-based ML | Preprocessing, TF-IDF, sentiment analysis |
| 6. Deep Learning | Neural networks | Keras/TensorFlow, CNN, RNN/LSTM |
| 7. Generative AI | LLMs | Prompt engineering, OpenAI API, diffusion intro |
| 8. Agentic AI | Autonomous agents | LangChain, task-driven & multi-agent workflows |
| 9. Django | Web backend | Models, views, ORM, admin panel |
| 10. FastAPI | Deployment | Async APIs, Pydantic, serving ML models |
| 11. Career Prep | Portfolio | Git/GitHub, resume, LinkedIn |

By the end, each phase's project work is browsable in the branches above — no separate list to maintain here.
